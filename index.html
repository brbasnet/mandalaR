Mandala Documentation

Mandala is an R mixed-model framework for plant breeding and quantitative genetics, with workflows for trial analysis, genomic prediction, spatial modeling, stage-wise analysis, and advanced variance structures.

Vignettes

Introduction to Mandala
Core syntax, model fitting, summaries, fixed tests, prediction, and diagnostics.
Single-Stage to Multi-Stage Analysis
Single-stage MET analysis, first-stage environment analyses, and second-stage synthesis.
Genomic Prediction
Genomic relationship models, tested and untested genotype prediction, and cross-validation.
Spatial Analysis
Row-column and spatial residual models for field trial analysis.
Advanced Variance Structures
FA, US, genomic, nested, and residual covariance structures.
Package Comparison
Positioning Mandala relative to common R breeding-analysis packages.
Public Example Data
Small datasets and a genomic relationship matrix used in the public vignettes.

This repository contains public documentation only. Private development source code is maintained separately.
